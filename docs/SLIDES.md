# Final presentation

Use [PDF](../slides/MedTech-Security-Baseline-Slides.pdf) or [editable PPTX](../slides/MedTech-Security-Baseline-Slides.pptx) for submission. Both contain 12 slides. The PPTX has English speaker notes, and the full script is also in [SPEAKER_NOTES.md](SPEAKER_NOTES.md). Suggested total is 16–18 minutes including demo and Q&A; actual timing requires rehearsal.

This revision preserves the CMU cover/tartan assets extracted from the original PDF. It adds both authors, fixes delivery-flow order, replaces tiny report details with readable native evidence, and adds an explicit value/cost model and pilot acceptance plan. Tables and diagrams are editable.

The [earlier Google Slides version](https://docs.google.com/presentation/d/11W8AE5Fn5un-FhWMLC6scesZQe5N5m9bFQFXPzMcSjA/edit) remains unchanged and is not the final revised deck. The hosted demo also remains a recorded replay; use demo/index.html as the local backup.

Source builder: scripts/build_slides.mjs, using @oai/artifact-tool for PPTX and PNGs. PDF companion uses LibreOffice because the bundled Artifact Tool PDF export has an unresolved standard-font alias. Rebuilding requires that tool/runtime and LibreOffice; viewing/editing the supplied PPTX needs neither. No native PowerPoint execution is claimed.

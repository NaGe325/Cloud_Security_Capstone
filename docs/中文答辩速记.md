# 答辩速记

你们做的是 Engineer Option A：用 Python/boto3 自动检查五类 AWS 配置，生成证据报告，并设计 Lambda 定时运行和通知流程。不是 Analyst 的十五项控制评估，也不是 Architect 的完整基础设施设计。

## 五类检查怎么讲

1. S3 公共访问防护：合并账号层和 bucket 层四个防护开关。失败表示预防配置不满足项目基线，不能直接说数据已经公开。
2. S3 默认加密：要求 KMS；AES256/SSE-S3 本身也是加密。不能说“没有 KMS 就没有加密”。
3. MFA：检查 root 和有控制台登录的 IAM 用户是否注册 MFA。注册不等于强制执行，SSO/联合身份不在范围内。
4. EC2 管理端口：找 IPv4/IPv6 对所有地址开放的 SSH 22、RDP 3389 规则。安全组开放不等于实际可达，数据库 3306 不在这项检查范围内。
5. CloudTrail：检查日志是否开启、覆盖管理事件读写、全局服务事件及 delivery error。不是完整审计合规检查。

## Demo 顺序

先本地打开 demo/index.html。Misconfigured 展示 root MFA 证据和通知预览；Compliant 展示六个 PASS 和一个 N/A；Incomplete 展示五个 PASS、一个 UNKNOWN、一个 N/A。解释“已评估的项目都通过”仍然可能证据不完整。

网站是记录回放；CLI 用 Stubber 执行实际检查代码。两者都不连接真实 AWS。命令退出码 0/1/2 分别表示通过、存在失败、证据不完整；1 不是程序崩溃。

## 第十页数字

假设每次人工十五分钟，自动化后仍需要五分钟审核；每天一次、三十天，节省三百分钟，即五小时。每小时六十美元是估值假设，三百美元表示释放的工作容量，不是已经省下的工资。

成本基于一个小账号、一个 bucket、us-east-1、每月三十次、256MB Arm、假设每次计费三十秒。模型基础小计约 0.012799 美元，向上取整到美分作为 0.02 美元预算；开启三项自定义指标、一个 dashboard、两个 alarm 后小计约 4.112799，向上取整预算 4.12。没有扣免费额度，也没包含原来的 EC2/RDS、税、额外传输和人工维护。真实账单和耗时都未测量。

## 老师追问时的边界

- 真实 AWS 没部署过；交付的是可运行离线实现与部署设计。
- 88 项测试通过说明离线逻辑和 mock API 行为，不证明生产运行。
- 当前没有持久化去重和漏跑检测，alarm 也没有通知动作。
- PASS 只代表五项基线在指定范围内通过，不能表示 HIPAA 合规。
- 先做受控试点，验证权限、存储、通知、定时运行和费用，再扩展。

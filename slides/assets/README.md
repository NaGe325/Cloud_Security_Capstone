# Font provenance

OpenSans-Variable.ttf is the unmodified variable Open Sans font from the official Google Fonts repository, ofl/opensans/OpenSans[wdth,wght].ttf, downloaded October 16, 2026. The SIL Open Font License is included in fonts/OFL.txt. Source: https://github.com/google/fonts/tree/main/ofl/opensans .

The slide artwork and branding remain embedded unchanged in slides/original/MedTech-Security-Baseline-Slides.pdf, copied from the source repository at commit 79d6c6e6a4a57d46495c8e77dea893503977b12e. The update script checks that source's SHA256 before editing. No original artwork was redrawn.

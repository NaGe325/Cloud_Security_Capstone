# Interactive demo backup

Open index.html in a browser. Keep app.js, data.js, style.css and reports/ alongside it. No build, server, AWS credentials or network access is needed for the local replay.

The three English scenarios replay actual offline Python results: compliant, misconfigured and incomplete. Switch scenarios, inspect findings and evidence, view input configurations and notification previews, and download JSON/HTML reports. This page does not execute Python or scan AWS.

Hosted version: https://medtech-security-checker-demo.nage32519.chatgpt.site/ (owner-private access).
